# HeisenBar — Sitio web de marca

Sitio web para HeisenBar, una barra móvil de cócteles para eventos privados y corporativos en Caacupé, Paraguay. Negocio propio, co-fundado y operado por mí.

## Stack técnico

Next.js + TypeScript, con animaciones interactivas dirigidas por scroll y un formulario de reservas integrado con WhatsApp.

## Características

- Animación de líquido en scroll, con efecto de splash al llegar a la sección final de la página.
- Formulario de reserva de eventos que envía los datos prellenados a WhatsApp Business.
- Identidad de marca propia (paleta blanco/marfil con acentos metálicos y colores de marca).
